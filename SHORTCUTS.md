# FocusDeck Keyboard Shortcuts

## Clocks
| Key | Action |
|-----|--------|
| C | Digital Clock |
| A | Analog Clock |

## Tools
| Key | Action |
|-----|--------|
| T | Timer |
| S | Stopwatch |
| P | Pomodoro |

## Controls
| Key | Action |
|-----|--------|
| Space | Start / Pause |
| R | Reset Current Session |
| ESC | Close Popup / Exit App |

## Display
| Key | Action |
|-----|--------|
| D | Dark Mode |
| L | Light Mode |
| Z | Toggle Zen Mode |

## Notes
- Switching between Clock and Analog Clock preserves sessions.
- Switching between Timer, Stopwatch, and Pomodoro resets the previous session.
- Zen Mode hides interface elements and focuses on the active timer.
