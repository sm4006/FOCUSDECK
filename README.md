
# FocusDeck

Minimal ambient productivity dashboard inspired by Fliqlo.

Turn any screen into a beautiful focus station.

## Features

- Digital Clock
- Analog Clock
- Custom Timer
- Stopwatch
- Pomodoro
- Zen Mode
- Dark / Light Theme
- Battery Display
- Media Detection
- Keyboard Only Controls
- Responsive UI

## Controls

C - Clock  
A - Analog Clock  
T - Timer  
S - Stopwatch  
P - Pomodoro  

SPACE - Start / Pause  
R - Reset  

D - Dark Mode  
L - Light Mode  
Z - Zen Mode  

ESC - Exit


## Built With

- psutil
