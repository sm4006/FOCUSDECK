# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in FocusDeck, please report it responsibly.

Please include:

- Description of the issue
- Steps to reproduce
- Potential impact
- Screenshots or logs if applicable

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.x.x | Yes |
| 0.x.x | No |

## Response Policy

Security reports will be reviewed and addressed as soon as possible.

Please avoid publicly disclosing vulnerabilities before a fix is available.
