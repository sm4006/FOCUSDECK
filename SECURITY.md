# Security Policy

## Supported Versions

| Version | Supported |
|---------|-----------|
| 1.0.1 | Yes |
| 1.0.0 | No |

---

## Reporting a Vulnerability

If you discover a security issue within FocusDeck, please open a GitHub Issue with details about the problem.

Please include:

- Steps to reproduce the issue
- Operating system and version
- FocusDeck version
- Screenshots if applicable

Security reports will be reviewed and addressed if they impact supported versions.
